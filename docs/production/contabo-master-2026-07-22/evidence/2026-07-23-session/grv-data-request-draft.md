# Draft — GRV data access request (owner to send)

**To:** E-Business Manager, Greyhound Racing Victoria (contact via grv.org.au/contact-us)
**From:** Daniel Fleuren, GreyhoundsIQ (greyhoundsiq.com.au)
**Subject:** Data access request — breeding and pedigree records (Topaz API / written consent)

---

Hello,

I operate GreyhoundsIQ (https://greyhoundsiq.com.au), an Australian greyhound
racing intelligence platform for owners, trainers and breeders. We provide
race form, breeding analytics and a "test mating" tool that shows the factual
historical record of a sire × dam pairing — actual litters, progeny results and
shared ancestry. We deliberately publish records of what has happened, not
predictions.

FastTrack's Terms and Conditions require GRV's written consent before its
information can be used beyond personal viewing, so I am writing to request
the appropriate authorised access — via the Topaz API and/or a written data
agreement — scoped to breeding and registry records:

1. Pedigree links to at least **five generations** (sire/dam identifiers per dog);
2. Litter records (sire, dam, whelping date, pup registrations);
3. Stud service records;
4. Registry identity fields for matching: registered name, whelp date, colour,
   sex, ear brand / microchip where permitted.

Intended use: enriching factual breeding pages and the test-mating tool on
GreyhoundsIQ with correct Victorian lineage data, with source attribution to
GRV. We do not operate wagering, do not on-sell raw data, and can meet any
technical, branding or reporting conditions GRV requires. Happy to discuss
commercial terms.

Could you let me know the application process and available scopes?

Kind regards,
Daniel Fleuren
GreyhoundsIQ — daniel.fleuren@aikickstart.com.au
